## Projects

### 01 — Python Image Toolkit

A beginner-friendly image processing utility built with Python and Pillow.

It can:

- Resize an image while preserving its aspect ratio
- Resize an image to exact dimensions
- Compress an image below a target file size
- Convert an image to grayscale
- Combine resizing and compression
